## 安装（2 分钟）

1. 下载 zip 并解压，得到 `AlphaDesk.app`，拖到"应用程序"（或放任意目录）。
2. **首次打开**：由于暂无 Apple 公证，macOS 会拦截——
   - 双击后若提示"无法验证开发者"，点"好"；
   - 打开「系统设置 → 隐私与安全性」，滑到底部点 **"仍要打开"**；
   - 只需操作一次，之后双击即用。
   - 更快的方法：**右键点击 App → 选择"打开"**，通常直接放行。
3. 双击 `AlphaDesk.app`，图标进 Dock，约 3 秒后浏览器自动打开 `http://127.0.0.1:8200`。
4. 退出：在 Dock 图标右键 → 退出（或浏览器标签关掉后 Dock 退出）。

> 要求：macOS 11+（Intel / Apple 芯片均可），磁盘 200MB，联网取行情。

## 常见问题

- **端口被占/打不开页面**：只开一个 App，关掉多余的再试；或换浏览器打开 `http://127.0.0.1:8200`。
- **换电脑**：把 `~/Library/Application Support/AlphaDesk` 文件夹拷到新电脑即可（自选/策略/回测记录都在里面）；激活码与机器绑定，换机联系卖家重发（年卡免费）。
- **行情延迟**：数据来自公开渠道，日线前复权，可能存在延迟，重要决策以券商软件为准。
